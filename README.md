# Симпсоны: Классификация персонажей

Проект по классификации персонажей мультсериала «Симпсоны» с использованием сверточных нейронных сетей и transfer learning. \
[Ссылка на Google Colab](https://drive.google.com/file/d/19gTN7gyR4YJZMBKeFZ9FSOOKgq_F3GBR/view?usp=drive_link) \
[Соревнование на kaggle](https://www.kaggle.com/competitions/journey-to-springfield1) 

## Результаты

| Модель | Test F1 Score |
|--------|---------------|
| Simple CNN | 0.94792 |
| ResNet18 | 0.708 |
| ResNet50 | **0.97236** |

## Архитектура

### Простая CNN
- 5 сверточных слоев
- MaxPooling после каждого слоя
- Полносвязный слой для классификации

### ResNet50
- Предобученная на ImageNet модель
- Замороженный backbone + дообучение головы
- Dropout для регуляризации

## Что было сделано

1) Написана базовая архитектура, состаящая из 5 сверточных слоев - Simple CNN
2) Провдвена аугментация латасета, но после этого нейронная сеть показала плохие результаты.
3) Пробовалось изменить сами слои и их количество, но результаты так же оказались неэффективны.
4) Simple CNN дообучена еще на 5 эпохах - результат улучшился.
5) Далее применялся transfer learning - ResNet18, ResNet50
6) ResNet18 с замороженным backbone показала хорошие результаты, но недостаточные.
7) ResNet50 с дообучением последних слоев показала отличные результаты - 0.97 на тестовой выборке.
